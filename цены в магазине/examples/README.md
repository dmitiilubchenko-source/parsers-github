# Примеры: METRO
`latest.json` — отчёт продуктовой корзины за 5 октября 2026 года.
`prices_2026-10-05_21-20-56_296977.*` — снимок этого запуска.
`weekly_prices.csv` — цены в руб/кг или руб/л; сохранена одна неделя.
`catalog_sample.csv` — первые 20 строк отдельного обычного снимка; это другой режим сбора.
Для сравнения динамики цен требуется следующий сопоставимый недельный замер.
Профиль браузера не включён: при новом запуске выберите тот же магазин, который указан в исходных данных.
