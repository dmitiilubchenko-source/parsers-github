# Примеры: выборы
`party_uik_1_22_sample.csv` — первые 20 УИК из специальной таблицы.
`summary_full_run.json` — отчёт полного сохранённого запуска.
Таблицы `04`–`07` — компактные сводные результаты полного сбора; их охват может отличаться от специальной партийной выгрузки. Смотрите соответствующий отчёт полноты.
Общий CSV, все протоколы, история, журналы и контрольные точки не включены.
Новый сбор: `python main.py collect --region "Республика Адыгея" --limit 6 --workers 2`.
Для обработки прежнего полного сбора скопируйте исходные данные из оригинального проекта в `data/`.
