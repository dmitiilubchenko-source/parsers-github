# Поля партийного протокола

Одна запись — один ID УИК. Строки 01–22 — печатные номера источника, не позиции массива.

- Строка 01: Число избирателей, внесенных в список избирателей на момент окончания голосования
- Строка 02: Число избирательных бюллетеней, полученных участковой избирательной комиссией
- Строка 03: Число избирательных бюллетеней, выданных избирателям, проголосовавшим досрочно
- Строка 04: Число избирательных бюллетеней, выданных участковой избирательной комиссией избирателям в помещении для голосования в день голосования

- Строка 07: Число избирательных бюллетеней, содержащихся в переносных ящиках для голосования
- Строка 08: Число избирательных бюллетеней, содержащихся в стационарных ящиках для голосования
- Строка 09: Число недействительных избирательных бюллетеней
