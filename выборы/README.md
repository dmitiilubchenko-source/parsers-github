# Парсер выборов в Государственную думу IX созыва, 2026

Python 3.10+, Selenium, Chrome и httpx. Selenium открывает официальный портал и получает параметры сессии; дерево комиссий и отчёты загружаются из JSON-сервиса ЦИК через httpx. Обработка сохранённых данных работает без интернета.

## Установка

```powershell
python -m pip install -r requirements.txt
```

Для сбора нужен установленный Chrome. Selenium Manager подбирает драйвер; первый запуск может потребовать загрузки драйвера.

## Команды

Запускайте из папки проекта. Справка: `python main.py --help`, подробные параметры: `python main.py collect --help`.

```powershell
# Небольшая проверка (6 УИК)
python main.py collect --region "Республика Адыгея" --limit 6 --workers 2
# Полный обход страны
python main.py collect --region all --limit 0 --workers 2
# Только отсутствующие и повреждённые ответы из последнего общероссийского отчёта
python main.py collect-missing --workers 2
# Обработка локальных данных и полный CSV
python main.py process
# Создание семи отдельных таблиц и небольших копий для просмотра
python report.py
# Только разбивка крупных CSV для просмотра
python report.py --split-only
# Только общий CSV, без пересчёта проверенных сводок
python main.py export-all --workers 4
# Повтор ошибочных запросов из последнего журнала сбора/дозагрузки
python retry_failures.py
```

`report.py` использует результаты `process`: при изменении исходных JSON сначала выполните `process`, затем `report.py`. `retry_failures.py` также принимает путь к конкретному JSONL-журналу.

При прерывании `collect` запускайте ту же команду: она использует контрольную точку. `--fresh` начинает новый обход с обновлением сохранённых ответов. `collect-missing` не строит дерево заново: читает список неполных УИК и пропускает уже восстановленные файлы. Предел потоков — 8; значение 2 является осторожной настройкой для полного сбора. Клиент повторяет временные ошибки, обновляет сессию при 401/403 и замедляет запросы при 429/502/503.

## Данные и результаты

- `data/raw/`: текущие исходные JSON: три дневных отчёта, протокол кандидатов и протокол партий.
- `data/history/`: прежние версии изменившихся ответов.
- `data/checkpoints/`: сохранённый прогресс обхода.
- `data/logs/`: отдельные журналы каждого запуска в JSONL и JSON; ошибки не останавливают остальные УИК.
- `data/processed/`: общий CSV `00_Все_данные_УИК_2026.csv`, таблицы `01`–`07`, описание и общий отчёт полноты.
- `data/processed/служебные/`: каталог УИК, нормализованные CSV, замечания, отчёты полноты и SQLite-кеш экспорта.
- `data/processed/Для_просмотра/`: части крупных CSV около 5 МБ с повторённой строкой заголовков.
- `data/archive/`: ранее убранные устаревшие результаты.

Таблицы `01`–`07`: все кандидаты по УИК; все партии по УИК; избиратели и бюллетени по УИК; суммы партий; партии по регионам; голосование и полнота по регионам; лидеры округов для анализа мандатов. Проигравшие участники также включены.

Общий CSV содержит одну строку на ID УИК из каталога и все поля пяти сохранённых ответов. Массивы разворачиваются по индексам, ключи экранируются по JSON Pointer. Позиции кандидатов в разных округах могут обозначать разных людей: для сумм используйте проверенные таблицы и идентификаторы. Отсутствующие поля пустые; отсутствие данных не заменяется нулём. История прежних версий в текущий CSV не входит.

Повторная обработка заменяет каждый CSV атомарно. Дубли проверяются по ID комиссии и строки; одинаковые дневные точки объединяются, конфликтующие исключаются с замечанием. Повторяющиеся ID итоговых протоколов у разных УИК исключаются из проверенных сумм. Убывающие дневные значения сохраняются и отмечаются. Общий экспорт сохраняет исходные поля даже при замечаниях проверки.

## Границы результата

В выполненном общероссийском сборе найдено 91 381 УИК; последний обсуждавшийся отчёт содержит 88 199 УИК с пятью ответами и 3 182 неполных. Эти цифры относятся к сохранённому запуску и могут меняться. Проверенные вручную отсутствующие дневные отчёты показывают «Нет данных для построения отчёта»; это не доказывает такую же причину каждого пропуска. HTTP 404 фиксируется как отсутствие ответа, остальные ошибки сохраняют свою причину.

Суммы показывают только собранные и пригодные протоколы. Лидер округа по этим данным не является подтверждением официального мандата. Партийные и кандидатские бюллетени не складываются. Адрес и населённый пункт не выдумываются, если их нет в исходных ответах. Поддержана конкретная кампания `587813923` и даты 18–20 сентября 2026 года; другая кампания требует настройки и проверки.
